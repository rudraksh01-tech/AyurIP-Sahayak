# ?? AyurIP-Sahayak

## ?? AI Assistant for Ayurveda, Traditional Knowledge & IPR

AyurIP-Sahayak is an AI-powered question-answering system that helps users learn about Ayurveda, Traditional Knowledge, Intellectual Property Rights (IPR), and TKDL.

## ?? In simple words

Imagine you have a very big book containing information about Ayurveda and IPR. Instead of reading hundreds of pages, you can simply ask a question.

### Example

**Question:** What is TKDL?

The system searches the project knowledge, finds relevant information, and uses AI to generate an easy answer.

## ?? How does it work?

AyurIP-Sahayak uses RAG (Retrieval-Augmented Generation).

``text
?? User asks a question
        ?
?? Search knowledge
        ?
?? Find relevant information
        ?
?? AI reads the information
        ?
?? Generate answer
        ?
?? User gets the answer
``
